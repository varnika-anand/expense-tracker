Expense Tracker

A web-based Expense Tracker application developed using PHP and MySQL. This project helps users manage and track their daily expenses through a simple and user-friendly interface.

Features

- User Registration
- User Login and Logout
- Add and manage expenses
- Store expense details in a MySQL database
- Display expense records with title, amount, category, and date
- Session-based user authentication

Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- Visual Studio Code

Installation and Setup

1. Install XAMPP on your computer.

2. Copy the project folder into the "htdocs" directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Create the required database using phpMyAdmin.

5. Configure the database connection in "db.php".

6. Open the application in your browser:
   
   "http://localhost/expense-tracker/"

Purpose

This project was developed to practice PHP programming, database connectivity, user authentication, and basic web application development.
